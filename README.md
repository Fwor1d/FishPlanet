# FishPlanet

Проект для подсчета рыбок и желтых полосатиков

**ООО «ГУДОК» | учебный проект по программной инженерии.** Система проектируется для учёта перемещений рыб между бассейнами: вида, количества, времени и бассейна назначения. Просмотр предназначен для сотрудников; управлять процессом может только технический администратор.

**Стадия:** опубликована документация ПЗ № 1–4. Программная реализация и индивидуальные Git-вклады участников не заявлены.
