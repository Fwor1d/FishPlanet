# Программная часть

Здесь будет располагаться реализация системы учёта перемещений рыб.

- `src/` — исходный код (пока не разработан).

Наличие папок **не означает**, что приложение реализовано. Механизм распознавания рыб и конкретное оборудование заказчик ещё не уточнил.
