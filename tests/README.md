# Тестирование

На этапе ПЗ № 4 программное тестирование не требуется, а реализация ещё не начата. Сценарии будущих проверок: успешный просмотр счётчика, пустые временные интервалы, недоступная запись, запрет операции сотруднику без права администратора.

Это **план проверок**, не свидетельство выполненных тестов. Результаты будут добавлены после реализации.
