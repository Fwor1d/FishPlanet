# Публикация проекта FishPlanet на GitHub

**Удалённый репозиторий:** https://github.com/Fwor1d/FishPlanet  
**Ветка:** `main`  
**Состояние перед загрузкой:** репозиторий создан, уже содержит первоначальный README.

## Автоматизированная первоначальная загрузка с macOS

1. Распакуйте ZIP с этой папкой в любое место, например `~/Downloads`.
2. Откройте Terminal и запустите `bash` с абсолютным путём к `publish-fishplanet.sh`, например:

```bash
bash ~/Downloads/FishPlanet-upload/publish-fishplanet.sh
```

Скрипт клонирует существующий GitHub-репозиторий в `~/Developer/FishPlanet` (вне папок iCloud/OneDrive), переносит документы, показывает список файлов и **спрашивает подтверждение перед коммитом и отправкой**. Начальная фраза README «Проект для подсчета рыбок и желтых полосатиков» сохраняется, дополняется навигацией по учебным файлам. Поле About на GitHub скрипт не меняет.

Скрипт отправляет всё **под именем реально выполняющего его пользователя**. Он не подменяет автора коммита и не подтверждает чужое ревью.
