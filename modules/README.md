# Модули системы

По текущим функциональным требованиям можно выделить **планируемые** области: учёт перемещений, счётчик и фильтрацию, временные интервалы, просмотр подробностей, административное управление.

Пока это логическое разбиение по UC-01–UC-04, а не реализованные программные модули. Код появится после уточнения источников событий и требований к оборудованию. Не нужно дублировать код между `modules/` и `projects/src/`.
