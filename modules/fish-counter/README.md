# Счётчик рыб

## Разработчик

За UC-01 по распределению команды отвечает Шейкин Д. М.

## Назначение

Модуль суммирует количество рыб каждого вида, переместившихся в выбранный бассейн за заданный период.

## Связанные требования

ФТ-01 и ФТ-02, [UC-01](../../docs/md/pz2-use-cases.md#вариант-использования-uc-01-просмотр-счётчика-перемещений), [SD-01](../../docs/draw/sd-01.mmd).

## Входные данные

ID бассейна назначения, начало и конец периода, файл UTF-8 JSON с массивами `pools` и `movements`. По умолчанию используется `demo.json` из каталога модуля.

## Результат

Функция `count_fish(data, pool_id, start, end)` возвращает ID и название бассейна, границы периода, словарь `counts_by_species` и число `total`. Пустому периоду соответствует пустой словарь и итог 0 (А2). Некорректные данные и обратный порядок границ (А1) дают `ValueError` в Python и сообщение с кодом 2 в консоли.

## Запуск

Из корня репозитория, Python 3.12, стандартная библиотека. На Windows вместо `python3` можно использовать `py -3.12`.

```sh
python3 modules/fish-counter/main.py
python3 modules/fish-counter/main.py 2 2026-11-20T10:00:00+03:00 2026-11-20T11:00:00+03:00
python3 modules/fish-counter/main.py 2 2026-11-20T07:00:00Z 2026-11-20T07:00:00Z
python3 modules/fish-counter/main.py 3 2026-11-20T07:00:00Z 2026-11-20T08:00:00Z
python3 modules/fish-counter/main.py 2 2026-11-20T08:00:00Z 2026-11-20T07:00:00Z
```

Команды показывают список бассейнов, итог 19 рыб (15 карпов и 4 форели), граничный итог 12 карпов, пустой результат и ошибку порядка дат соответственно. Опция `--data путь.json` подключает другой файл.

## Текущее состояние

Модуль считает по зарегистрированным в локальном файле событиям. В расчёте участвуют бассейн назначения, время события, вид и количество рыб.

## Общий формат данных

Корневой объект JSON соответствует словарю Python. Каждый модуль использует только нужные ему массивы. В [demo.json](demo.json) приведён полный пример.

| Массив | Поля объекта |
| --- | --- |
| `pools` | `id`, `name` (название бассейна) |
| `movements` | `id`, `species` (вид), `count` (целое число рыб от 1), `destination_pool_id` (ссылка на `pools.id`), `occurred_at` (время события), `duration_seconds` (целое число секунд от 0) |
| `intervals` | `id`, `start`, `end` (начало и конец периода) |
| `users` | `id`, `role` (`technical_admin` или `employee` в демонстрационных данных) |

Идентификаторы — положительные целые числа, уникальные внутри массива. Названия и виды — непустые строки. Время записывается в ISO 8601 с секундами и обязательным часовым смещением `Z` или `±HH:MM`. Допускается до шести цифр дробной части секунды. Время сравнивается с учётом смещения. Обе границы интервала включены, начало может совпадать с концом. Ключи используют `snake_case`.
