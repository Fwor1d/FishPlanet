# Детали перемещения

## Разработчик

Гогичашвили Г. Л.

## Назначение

По ID перемещения модуль показывает вид и количество рыб, бассейн назначения, точное время события и длительность переплыва.

## Связанные требования

[ФТ-01](../../docs/md/pz2-use-cases.md#исходные-функциональные-требования) и [ФТ-04](../../docs/md/pz2-use-cases.md#исходные-функциональные-требования), [UC-03](../../docs/md/pz2-use-cases.md#вариант-использования-uc-03-просмотр-сведений-о-перемещении), [SD-03](../../docs/draw/sd-03.mmd).

## Входные данные

Положительный целый ID перемещения и файл UTF-8 JSON с массивами `movements` и `pools`. По умолчанию загружается [пример](demo.json) из каталога модуля. Формат полей описан [ниже](#общий-формат-данных).

## Результат

Функция `get_movement_details(data, movement_id)` возвращает поля выбранной записи и `destination_pool_name`. При отсутствии ID она возвращает `None`, при некорректном запросе или данных выбрасывает `ValueError`. Консоль выводит JSON при успехе и сообщение об ошибке в stderr. Код завершения 1 означает, что запись недоступна (А1), код 2 означает ошибку запроса или загрузки (А2 для ошибки данных).

## Запуск

Из корня репозитория, Python 3.12, стандартная библиотека. На Windows вместо `python3` можно использовать `py -3.12`.

```sh
python3 modules/movement-details/main.py 101
python3 modules/movement-details/main.py 1
python3 modules/movement-details/main.py 999
python3 modules/movement-details/main.py 0
python3 modules/movement-details/main.py 101 --data missing.json
```

ID 101 показывает запись о 12 карпах и переплыве длительностью 45 секунд. ID 1 проверяет нижнюю границу для ID и нулевую длительность, 999 отсутствует, 0 некорректен. Последняя команда проверяет ошибку чтения. При запуске без ID модуль просит ввести его в консоли.

## Текущее состояние

Модуль открывает локальный JSON на чтение. Он поддерживает прямой запуск по ID, который в следующей работе можно передать после выбора записи в UC-02.

## Общий формат данных

Корневой объект JSON соответствует словарю Python. Каждый модуль использует только нужные ему массивы. В [demo.json](demo.json) приведён полный пример.

| Массив | Поля объекта |
| --- | --- |
| `pools` | `id`, `name` (название бассейна) |
| `movements` | `id`, `species` (вид), `count` (целое число рыб от 1), `destination_pool_id` (ссылка на `pools.id`), `occurred_at` (время события), `duration_seconds` (целое число секунд от 0) |
| `intervals` | `id`, `start`, `end` (начало и конец периода) |
| `users` | `id`, `role` (`technical_admin` или `employee` в демонстрационных данных) |

Идентификаторы — положительные целые числа, уникальные внутри массива. Названия и виды — непустые строки. Время записывается в ISO 8601 с секундами и обязательным часовым смещением `Z` или `±HH:MM`. Допускается до шести цифр дробной части секунды. Время сравнивается с учётом смещения. Обе границы интервала включены, начало может совпадать с концом. Ключи используют `snake_case`.
