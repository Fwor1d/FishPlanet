# Временные интервалы

## Разработчик

За UC-02 по распределению команды отвечает Амелякин М. И.

## Назначение

Модуль показывает доступные интервалы и перемещения за выбранное время. В интерактивном режиме доступен текстовый календарь месяцев, в которых начинаются интервалы.

## Связанные требования

ФТ-03, [UC-02](../../docs/md/pz2-use-cases.md#вариант-использования-uc-02-просмотр-списка-временных-интервалов), [SD-02](../../docs/draw/sd-02.mmd).

## Входные данные

Файл UTF-8 JSON с массивами `intervals` и `movements`, при выборе интервала также нужен его положительный целый ID. По умолчанию используется `demo.json` из каталога модуля.

## Результат

`list_intervals(data)` возвращает интервалы в порядке начала. `get_interval_movements(data, interval_id)` возвращает выбранный интервал и список перемещений в порядке времени события, а при неизвестном ID — `None`. Пустой календарь (А1) и пустой выбранный интервал имеют разные сообщения. В режиме `--interactive` пустой ввод, «отмена» или Ctrl+C на шаге выбора возвращают к календарю (А2). При выборе записи выводится её `movement_id` для передачи в UC-03. Консоль возвращает код 1 при неизвестном ID интервала и 2 при недопустимом запросе или данных.

## Запуск

Из корня репозитория, Python 3.12, стандартная библиотека. На Windows вместо `python3` можно использовать `py -3.12`.

```sh
python3 modules/time-intervals/main.py
python3 modules/time-intervals/main.py --interactive
python3 modules/time-intervals/main.py 2
python3 modules/time-intervals/main.py 1
python3 modules/time-intervals/main.py 3
python3 modules/time-intervals/main.py 999
```

Интервал 2 включает записи 101, 102 и 103, в том числе события на обеих границах. Интервал 1 совпадает по началу и концу и содержит запись 1. Интервал 3 пуст, а 999 отсутствует. Чтобы проверить А1, подключите файл с `"intervals": []` через `--data путь.json`.

## Текущее состояние

Выбор выполняется по ID из списка под текстовым календарём. Источником интервалов является локальный JSON. Переход к UC-03 представлен выдачей ID выбранного перемещения.

## Общий формат данных

Корневой объект JSON соответствует словарю Python. Каждый модуль использует только нужные ему массивы. В [demo.json](demo.json) приведён полный пример.

| Массив | Поля объекта |
| --- | --- |
| `pools` | `id`, `name` (название бассейна) |
| `movements` | `id`, `species` (вид), `count` (целое число рыб от 1), `destination_pool_id` (ссылка на `pools.id`), `occurred_at` (время события), `duration_seconds` (целое число секунд от 0) |
| `intervals` | `id`, `start`, `end` (начало и конец периода) |
| `users` | `id`, `role` (`technical_admin` или `employee` в демонстрационных данных) |

Идентификаторы — положительные целые числа, уникальные внутри массива. Названия и виды — непустые строки. Время записывается в ISO 8601 с секундами и обязательным часовым смещением `Z` или `±HH:MM`. Допускается до шести цифр дробной части секунды. Время сравнивается с учётом смещения. Обе границы интервала включены, начало может совпадать с концом. Ключи используют `snake_case`.
